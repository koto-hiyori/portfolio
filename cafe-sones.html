Cafe SONES

カフェサイト

制作時期 2026年5月
制作期間 累計4日
使用技術 HTML / CSS / Bootstrap / JavaScript / jQuery / Vue.js / CSSアニメーション / Google Fonts / Font Awesome / Slick / ChatGPT / Gemini / Visual Studio Code
GitHub デモサイトを見る

概要

職業訓練校の課題として、カフェのWebサイトをリニューアルすることを想定して制作しました。※学習を目的としており、公式サイトではありません。

機能

スライドショーの実装
CSSアニメーションの実装
ページトップへ戻るボタンの設置
アクティブページの表示

制作のポイント

スライドショー

初めてサイトを訪れたユーザーに、カフェの魅力やこだわりが直感的に伝わるよう、料理や店内の写真が切り替わるスライドショーをSlickで実装しました。

CSSアニメーション

カフェらしい雰囲気を演出するため、背景にコーヒーのイラストがゆっくり回転するアニメーションを実装しました。主張しすぎない速度や動きに調整し、コンテンツを邪魔せずにサイト全体の世界観を表現しています。

レスポンシブ対応

Bootstrap5やメディアクエリを活用し、PC・タブレット・スマートフォンの各デバイスで快適に閲覧できるよう工夫しています。
