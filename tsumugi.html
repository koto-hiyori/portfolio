TSUMUGI

「大島紬」のショッピングサイト

制作時期 2026年6月
制作期間 累計3日
使用技術 HTML / CSS / Bootstrap / JavaScript / Vue.js / Google Antigravity / Font Awesome / Google Fonts / ChatGPT / Gemini / Visual Studio Code
GitHub デモサイトを見る

概要

「大島紬」を日常に取り入れてもらえるように、現代の日常に調和させ、日々に寄り添う上質なスタイルを提案。オンライン販売を行うことで、若年層や新規購入者の開拓を目指しました。

機能

ヘッダーにカート内の商品数の表示
お問い合わせフォームのバリデーションチェック
アクティブページの表示

制作のポイント

AI活用

Google Antigravityを使用。プロンプトとして「サイトの概要・ページ構成・使用する言語/フレームワーク」を指示し、生成されたソースコードをもとに制作しました。

SPA形式で制作

ユーザーの離脱を防ぐために、高速表示とスムーズな操作を実現し、UXの向上を行いました。

デザイン

ベージュ・ブラック・ゴールドを基調とした配色を採用し、余白を十分に確保することで落ち着いた雰囲気を演出しました。装飾を最小限にすることで、商品や写真が引き立つよう工夫しています。
