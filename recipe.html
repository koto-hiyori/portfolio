わが家の味メモ

レシピ共有アプリ

制作時期 2026年7月
制作期間 累計7日
使用技術 HTML / CSS / Bootstrap / JavaScript / jQuery / Vue.js / CSSアニメーション / Google Fonts / Font Awesome / Slick / ChatGPT / Gemini / Visual Studio Code
デモサイトを見る

概要

家族でグループを作り、レシピを共有するWebアプリケーションです。大切なわが家の味を受け継いでいき、食べたい時に気軽に作れるようにしたいと考え、このアプリケーションを制作しました。

機能

CRUD機能
「いいね」ボタン
ページトップへ戻るボタンの設置
アクティブページの表示

制作のポイント

CRUD機能

レシピ登録、レシピの編集・削除、新規アカウント作成、ログイン、ログアウト、グループ作成機能を実装しました。

いいね機能

「いいね」ボタンは、少人数でレシピを共有していることを考慮し、1人が何度でも押せるように工夫しました。レシピを見返した時や実際に料理を作った時に都度「いいね」を押すことが出来ます。

レスポンシブ対応

Bootstrap5やメディアクエリを活用し、PC・タブレット・スマートフォンの各デバイスで快適に閲覧できるよう工夫しています。
