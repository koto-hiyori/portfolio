銅山温泉旅館「琥珀」

温泉旅館の宿泊予約サイト

制作時期 2026年7月
制作期間 累計10日間
担当範囲 交通案内ページ・観光スポットページ・お知らせページ・デザイン調整・プレゼンテーション資料作成
使用技術 HTML / CSS / Bootstrap / JavaScript / jQuery / Vue.js / PHP / WordPress / Font Awesome / ChatGPT / Gemini / Figma / Canva
GitHub デモサイトを見る

概要

職業訓練校のチーム制作課題として7名で制作した、温泉旅館の宿泊予約サイト。ユーザーは簡単に宿泊予約を進めることができ、温泉施設の情報も確認できます。近年の宿泊・温泉業界の傾向が「体験型観光」であるため、独自コンテンツを設け「旅全体の体験価値」を高める仕様となっています。

機能

予約時に宿泊日を選択しやすいカレンダー
予約ページのパンくずリスト
フォームのバリデーションチェック
フォームの送信と自動応答メールの配信

制作のポイント

使いやすいUI

ターゲットユーザーを30~60代に設定しているため、シンプルで直感的に操作できるUIを意識して設計しました。

独自コンテンツの設置

宿泊だけでなく「旅全体の体験価値」を高めるために、「琥珀」ならではの独自コンテンツを設けました。おすすめの過ごし方や、周辺の観光スポットから旅館までの時間を記載し、旅行の計画を立てやすいサイトを目指しました。

デザイン

温泉旅館の魅力が伝わるよう、写真を大きく使用し、落ち着いた配色と余白を意識したデザインにしました。
