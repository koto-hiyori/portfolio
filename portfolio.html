ポートフォリオ

ポートフォリオサイト

制作時期 2026年7月
制作期間 累計5日
使用技術 HTML / CSS / Bootstrap / JavaScript / jQuery / Vue.js / CSSアニメーション / Google Fonts / Font Awesome / Slick / ChatGPT / Gemini / Canva / Visual Studio Code
GitHub

概要

職業訓練校で学んだ技術を活かして制作したポートフォリオサイトです。シンプルで統一感のあるデザインを心がけ、作品の詳細ページやモーダルによる画像ギャラリーを実装しました。

機能

パンくずリストの表示
ページトップへ戻るボタンの設置
フォームのバリデーションチェック
フォームの送信と自動応答メールの配信
アクティブページの表示

制作のポイント

フォームのユーザビリティ向上

Vue.js(ver2.7)でお問い合わせフォームにバリデーションチェックを実装し、入力ミスによるユーザーの離脱を防ぎます。SSGFormの自動応答メールを活用することで、相互に送信内容を確認できるように工夫しました。

モーダル表示

作品の画像をモーダルで表示。画面遷移せずにスムーズに閲覧することが可能です。

レスポンシブ対応

Bootstrap5やメディアクエリを活用し、PC・タブレット・スマートフォンの各デバイスで快適に閲覧できるよう工夫しています。
